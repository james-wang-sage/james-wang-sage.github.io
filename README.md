# james-wang-sage.github.io

Personal tech blog, served by GitHub Pages (built-in Jekyll, `minima` theme) at
https://james-wang-sage.github.io/.

## Post

1. Add `_posts/YYYY-MM-DD-slug.md` with front matter (`layout: post`, `title`, `tags`,
   `image`).
2. Give it a cover: `assets/images/<post-file-stem>-cover.jpg`, a ~2.38:1 banner with no text,
   referenced from `image:` and shown at the top of the post.
3. Check every factual claim against primary sources before publishing.
4. Push to `main`; Pages builds it in about a minute.
5. Cross-post to dev.to as a draft, without `canonical_url` (dev.to would show an
   "Originally published at" line), and publish it there after review.

This repository is public: nothing internal to an employer (hostnames, internal URLs, ticket
or customer data) goes in any commit — git history is public too.
