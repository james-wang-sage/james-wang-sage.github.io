# Legacy blog redirects

The live blog and all future posts are maintained at https://kaopu-ai.github.io/ in
https://github.com/Kaopu-AI/kaopu-ai.github.io.

This repository keeps the previous site address working. Existing HTML pages redirect
to the same paths on the new host; JavaScript preserves query strings and anchors.
A 404 fallback handles unlisted paths. Assets remain available for old direct downloads.
The Atom feed is a migration snapshot; RSS readers should subscribe to
https://kaopu-ai.github.io/feed.xml for future updates.
