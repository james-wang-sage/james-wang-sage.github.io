# james-wang-sage.github.io

Personal tech blog, served by GitHub Pages (built-in Jekyll, `minima` theme) at
https://james-wang-sage.github.io/.

## Post

1. Add `_posts/YYYY-MM-DD-slug.md` with front matter (`layout: post`, `title`, `tags`).
2. Push to `main`; Pages builds it in about a minute.
3. Cross-post to dev.to as a draft with `canonical_url` set to the post's URL here, so
   this site stays the original.

This repository is public: nothing internal to an employer (hostnames, internal URLs, ticket
or customer data) goes in any commit — git history is public too.
